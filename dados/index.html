Dados

Indicadores e bases tratadas do Projeto DSIP-MT para download

Bases tratadas da Fase I, congeladas em 08/07/2026. Os arquivos para download são cópias fiéis das bases entregues, exceto pelo IFDM (ver nota ao final).

Explorador de indicadores

A tabela traz o último valor de 54 indicadores para os 141 municípios de Mato Grosso. Use os filtros de cada coluna e o botão para baixar o recorte filtrado em CSV.

Bases tratadas

Cada base tem uma linha por município e ano (ou por município, nas bases de retrato único). A chave id_municipio é o código IBGE de 7 dígitos.

Além das bases por dimensão:

  • Painel dos 141 municípios e painel do Pantanal Norte
  • Tabela de municípios e grupos
  • Dicionários de variáveis: D1 · D2 · D3 · D4 · D5 · D6 · Painel
  • Malha municipal de MT simplificada (GeoJSON) — IBGE, simplificada para uso na web
  • Catálogo das bases

Todos os arquivos estão em UTF-8, separados por vírgula. Valores monetários reais estão em reais de 2024 (deflatores descritos nas notas metodológicas).
